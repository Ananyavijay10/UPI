SYSTEM ARCHITECTURE

How It Works

01

Transaction Data

Captures 11 telemetry parameters: Amount (₹), Time-risk, Transaction Category, Frequency velocity, Baseline deviation, Beneficiary history, Device, and Location alterations.

02

ML Risk Analysis

Feeds normalized features through a multi-model Scikit-Learn ColumnTransformer pipeline (StandardScaler + OneHotEncoder) powered by a 100-tree Random Forest ensemble.

03

Fraud Detection

Calculates exact risk scores (0–100), maps decision tiers (Safe, Suspicious, Fraud Likely), and generates human-interpretable Explainable AI risk indicators.

DEFENSIVE CAPABILITIES

Core Platform Features

Machine Learning

Compares Random Forest, Gradient Boosting, Logistic Regression, and Decision Tree with benchmark metrics: Accuracy, Precision, Recall, F1, and ROC-AUC.

Risk Scoring

Granular risk severity classification spanning LOW (0–30), MEDIUM (31–60), HIGH (61–80), and CRITICAL (81–100) with dynamic radial visual gauge.

Explainable Indicators

Clear separation between probabilistic model scores and deterministic rule-based triggers, explaining why anomalies were highlighted.

Transaction Analytics

Interactive Chart.js visual dashboard illustrating volume trends by hour, risk distributions, and categorical breakdowns directly from SQLite.

Fraud Alerts & Verification

Simulated two-tier authentication alerts allowing users to verify cleared transactions or halt high-risk anomalies.

Admin Control Center

Privileged management console for monitoring system-wide transactions, tracking real-time fraud rates, and triggering on-demand pipeline retraining.
